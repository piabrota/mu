# Legal

The licence terms for this repository and piabrota's public repositories.

## Licences

| What | Licence | Why |
| --- | --- | --- |
| What piabrota writes new, and new piabrota repositories | MPL-2.0 | the org's default; each project names its own licence |
| Scripts that came from Ouroboric (`scripts/`) | AGPL-3.0-only | the licence they came under; piabrota can't change it alone |
| Documentation that came from Ouroboric | CC BY 4.0 | the licence it came under; it requires credit |
| Names and logos | reserved | see [TRADEMARKS.md](../../../TRADEMARKS.md) |

[NOTICE.md](../../../NOTICE.md) keeps the credit and lists what changed. [`REUSE.toml`](../../../REUSE.toml)
assigns a licence to each path.

A script that combines AGPL-3.0-only code stays AGPL-3.0-only, whatever new code it gains.
